Établir la CI minimale, reproductible et bloquante exigée par D5 — `install → tests → build → artefact` — à partir des commandes réelles de `package.json`, sans remplacer l'infrastructure existante.

- Les workflows existants (`pages.yml`, `android-build.yml`) valident désormais les tests avant leurs actions.
- La CI prépare le terrain pour G2 sans l'implémenter : aucun moteur aléatoire touché.
